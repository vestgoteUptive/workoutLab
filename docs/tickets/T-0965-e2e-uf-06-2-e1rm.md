## Why
The card, chart and table are built in T-0963 and covered there at unit and component level. This ticket proves the flow in a real browser, including offline and the edge cases that need a real clock, cache and focus.

## Scope
- In: one new spec `tests/e2e/uf-06-2-estimated-1rm.spec.ts` using the existing fixtures (no change to fixtures).
- Out: any app, engine or fixture change; if a test needs a fixture change, raise a follow-up.

## Acceptance criteria
Each criterion becomes at least one Playwright test.
- AC1 (zero history) Given an account with no sets of back-squat, When opening UF-06.2 for it, Then only the existing empty line shows: no Est. 1RM card, no chart, no estimate message.
- AC2 (one session) Given one back-squat session of 100 x 8, Then "Est. 1RM" "about 127 kg" shows, the chart has one dot and no line, "One session so far. Log it again to see a trend." shows and there is no delta line.
- AC3 (trend and 10 days off) Given sessions on day -40 (100 x 8), day -20 (105 x 8) and day 0 after a 10-day gap with a lower 95 x 8, Then the card shows the last value, the delta line reads "Down" or "Up" in words matching the first-versus-last rounded kg, and the x gap is proportional (the 20-day dot spacing is about twice the 10-day one within 2 px).
- AC4 (offline) Given a warm cache, When the browser goes offline and the page is reloaded, Then card, delta and chart show the same values as online and the offline status line shows; and given a set logged offline (queued), Then it appears in the estimate when it is the session's best.
- AC5 (window) Given one session 57 days old and one 3 days old, Then only the second is plotted (one dot); with the old one at 56 days, both are plotted.
- AC6 (no valid set and kinds) Given only 60 x 15, Then "No estimate yet. Estimates need a weighted set of 1–10 reps." shows and no card. Given plank or push-up, Then "Estimated 1RM is for weighted lifts."
- AC7 (table and focus) Given two or more points, When pressing "Show as table" with the keyboard, Then `aria-expanded` is true, the table with caption "Estimated 1RM per session" lists one row per point oldest first, the chart stays visible, and focus stays on the toggle; pressing again hides it.
- AC8 (a11y and size) Given UF-06.2 with a chart, Then axe reports no violations and the toggle is at least 44 px tall; at a 320 px viewport nothing overflows horizontally.
- AC9 (scope) Given a workout in progress (UF-08 and UF-09) and Today (UF-02.1), Then no "Est. 1RM" text, chart or "about N kg" estimate appears, and "Latest PR" shows the actual set.

Checklist (D-0197 §7): the offline/online pair is AC4 (online values are the baseline, offline asserted equal); empty/non-empty are AC1 and AC2; first launch vs returning is AC1 and AC3; no migration.
