# T-0907: deploy.yml builds design-tokens before web

- Lane: infra (CI fix)
- Source: PR #38 preview job failed: `Rollup failed to resolve import "@workoutlab/design-tokens/tokens.css"`.

## Why
`tokens.css` is generated by `packages/design-tokens` (`build-css.mjs`) and gitignored. `infra/scripts/deploy-prod.sh` builds design-tokens first. `deploy.yml` didn't, so every preview build failed on a fresh runner. The production job has the same steps, so it would have failed too once `PROD_DEPLOY_ENABLED=true` is set.

## Acceptance criteria
- AC-1: both the preview and production jobs build `@workoutlab/design-tokens` before `@workoutlab/web`.
- AC-2: `check-deploy-workflow.mjs` enforces AC-1. A planted fault (the step removed) is red for both jobs.
- AC-3: on a fresh worktree, `design-tokens build`, `web build` and `landing build` all succeed.
- AC-4: the PR's preview job is green.
