## Why
`parseSessionPlan` compiles its JSON Schema at runtime with Ajv, which uses `new Function`. The PWA's CSP is `script-src 'self'` with no `'unsafe-eval'` (T-0300a AC-A10). In the built app the compile throws, every `sessions.plan` reads as `invalid`, and UF-09 focus mode can never start (TR-0036). D-0117 keeps the CSP and moves the compile to codegen time.

## Scope
- In:
  - `packages/shared/scripts/gen-api.ts`: a new export, `generateSessionPlanValidator()`, plus writing `src/session-plan.validate.gen.ts` when the script runs as main. It uses `ajv/dist/standalone` on `SESSION_PLAN_SCHEMA`. The options are `strict: true`, `allErrors: false`, `allowUnionTypes: true`, `unicode: false`, and `code: {source: true, esm: true}`. The output has the GENERATED header, `// @ts-nocheck`, and is formatted with the repo Prettier config. If the standalone code contains any `require(` or `import`, the generator throws, naming the module (D-0117 §1).
  - `packages/shared/src/session-plan.validate.gen.ts`: generated and committed.
  - `packages/shared/src/session-plan.ts`: imports the generated function behind a typed `(value: unknown) => boolean` wrapper. It removes the `ajv/dist/2020.js` import, the lazy compile and the `validator === null` branch. The D-0043 §4 semantics are unchanged.
  - `packages/shared/eslint.config.mjs`: ignore `src/*.validate.gen.ts`.
  - `packages/shared/test/`: new tests for AC1 to AC5.
  - `apps/web/build.test.ts`: the bundle scan (AC6).
  - `tests/e2e/csp-session-plan.spec.ts`: the real-CSP browser proof (AC7).
  - `supabase/functions/_shared/vendor/shared/**`: regenerated with `node supabase/scripts/vendor.mjs`, never edited by hand (AC8).
- Out:
  - The CSP, `apps/web/vite.config.ts`, and the T-0300a AC-A10 test. They stay exactly as they are.
  - `api/openapi.yaml`, `docs/data-model.md`, and `docs/engine-rules.md`.
  - `packages/shared/package.json` dependencies and `pnpm-lock.yaml`. `ajv` stays a `dependency` (D-0117 §6).
  - Both `deno.json` files and `supabase/tests/scripts/functions-platform.test.mjs`. The `ajv/dist/2020.js` mapping becomes unused but stays.
  - T-0304a's `test.fail` marker. T-0304a removes it after it rebases (D-0117 §7).
  - Any UF-09 code.
