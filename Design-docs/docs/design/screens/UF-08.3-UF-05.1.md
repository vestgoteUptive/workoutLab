# UF-08.3 Swap before starting and UF-05.1 Swap sheet: "Don't suggest again" checkbox

- **Screens:** UF-08.3 Swap before starting and UF-05.1 Swap sheet (in workout). One spec: the two screens share the control and the empty state.
- **Decisions:** D-0199 (§9 empty states, §10 design). Spec: `docs/specs/excluded-exercises.md`.
- **Look:** Cobalt + state colour (D-0208); state `plan`; patterns in `components/state-patterns.md`.
- **Components:** C-03 Checkbox (`../components/c-03-checkbox.md`). Tokens: existing only.

## Checkbox

- **Label:** "Don't suggest {current name} again" ({current name} is the exercise being swapped out, for example "Don't suggest Barbell row again"). A C-03 checkbox: native input inside its label, 22 px box, row at least 44 px, wraps.
- **Default:** unchecked, every time the screen opens.
- **Position:** UF-08.3: directly under "Always use this in <routine>" (when that option is shown), above the confirm button, with 8 px between them. UF-05.1: below the alternatives list and above the confirm button, in the same place.
- **When it applies:** only when the swap is confirmed. Ticking it changes nothing by itself. With the box unticked, nothing is stored. Cancelling the sheet stores nothing.
- **In workout (UF-05.1):** reached only from UF-09.9 Pause and UF-09.6 Next. It changes the swap being confirmed and future suggestions, never the rest of the running plan. **Nothing is added to UF-09.1 to UF-09.9** (principle 1): the checkbox is in the sheet behind Pause.

## States

| State | What shows |
|---|---|
| Online | Checkbox enabled |
| Offline | The checkbox has `aria-disabled="true"` and cannot be ticked. `aria-describedby` points at one line: "Connect to change excluded exercises" (`--wl-ink-muted`, 13 px, under the checkbox). **The swap itself still works offline** and the confirm button is not disabled. A box ticked before the connection dropped is cleared |
| Write fails (online) | The swap is applied; the exclusion is not stored. "Couldn't save. Try again." (`role="alert"`) shows and the box stays ticked so the user can retry from the same sheet. If the swap is already applied and the sheet closed, the message shows on the screen the user returns to |
| Excluded alternatives | Never listed. The list is `rankSwaps` with the stored list |

## Empty state: no alternatives

- When `rankSwaps` with an empty exclusion list returns candidates but the real call returns none: "No alternatives left. The others are excluded." (`--wl-ink-muted`, in the list area).
- Otherwise the existing "No alternatives fit your equipment".
- In both empty cases there is nothing to confirm, so the checkbox is not shown.

## Accessibility (D-0199 §10)

- Native checkbox in its label; the state is announced by the browser. Label unique on the screen.
- Offline: `aria-disabled` plus one `aria-describedby` "Connect to change excluded exercises" per screen.
- "Couldn't save. Try again." is `role="alert"`.
- Row at least 44 px, box 22 px, border `--wl-ink-muted` 5.9:1 on `plan.bg` (needs 3), focus ring 2 px `--wl-focus`, offset 2 px.
