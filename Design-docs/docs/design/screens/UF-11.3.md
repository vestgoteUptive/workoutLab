# UF-11.3 Edit plan

- **Screen:** UF-11.3 Edit plan, route `/plan/edit` (no tab bar). Reached from the UF-11.2 "Edit plan" button and from the UF-11.6 level notice link "Change level" (`/plan/edit?from=favorites`). Never reachable from UF-03, UF-08 or UF-09.
- **Decisions:** D-0230 (Level on this screen, level-only save), D-0233 §1–§2 (the Level control, its name and hint captions), §3 (Advanced hint copy), §8 (focus on return to UF-11.6), D-0231 (the "Change level" entry point), D-0070 §3 (the three-write save), D-0081 §2 (the draft is fixed at first read), D-0203 (visual foundation). Spec: `docs/specs/editable-level.md` (AC1, AC2, AC4–AC6, AC9) and `docs/specs/uf-11-plan-checkin.md` (UF-11.3).
- **Look:** Cobalt + state colour (D-0208); state `plan`; patterns in `components/state-patterns.md` (Selected option row, Segmented control, Chip, Primary button, Text button).
- **Foundation classes (D-0203):** `.wl-page` (gutter), `.wl-option` (selected option row), `.wl-segmented`, `.wl-chip`, `.wl-label`, `.wl-button--primary`, `.wl-button--text`.
- **Tokens:** existing `--wl-` variables only: `--wl-bg`, `--wl-raise`, `--wl-line`, `--wl-ink`, `--wl-ink-muted`, `--wl-ink-on-raise`, `--wl-selected`, `--wl-on-selected`, `--wl-action`, `--wl-on-action`, `--wl-focus`. No new token, no raw colour value.
- **Components:** none new. The Level group reuses the Goal group's control.

## What this screen is for

Change the plan: goal, training level, how often you train and which areas come first. The target preview shows what the rhythm and priority areas do to the hard-set targets before anything is saved. Level changes which exercises are suggested (engine rule 0), never the targets (rule 4), and the screen says so in words.

## Layout (top to bottom)

The screen root is `.wl-page` (20 px gutter, 640 px max width, 16 px between blocks). Section order:

1. **Header**: `<h1>` "Edit plan" (page title style, with the decorative stop). Then the offline line `OfflineStatus variant="text"` (only offline).
2. **Goal**: `role="radiogroup"` named "Goal", three `.wl-option` rows on native radios: "Build muscle", "Get stronger", "General fitness". Unchanged.
3. **Level**: `role="radiogroup"` named "Level", three `.wl-option` rows on native radios: Beginner, Intermediate, Advanced, each with a hint caption, then one static line. New (D-0230, D-0233 §1). Detail below.
4. **Rhythm**: `role="group"` named "Sessions per week": two steppers ("Minimum", "Maximum", 1–7, a `.wl-segmented` pair of − and + buttons each) and the line "{min}–{max} per week". Unchanged.
5. **Priority areas**: `role="group"` named "Priority areas": nine `.wl-chip` toggles (`aria-pressed`) in the fixed area order (chest, back, shoulders, arms, core, glutes, quads, hamstrings, calves), up to 3. A `role="status"` line under the chips says "Pick up to 3" when a fourth is tapped. Unchanged.
6. **Target preview**: a section with the `.wl-label` heading "New targets per 14 days" and a list of "{Area} {sets}" rows divided by a 1 px `--wl-line` rule. Computed from rhythm and priority areas only. Unchanged.
7. **Save-failed alert and offline line**: "Couldn't update your plan. Try again." (`role="alert"`, only after a failed save) and "Connect to save" (caption, `--wl-ink-muted`, only offline).
8. **Cancel and Save**: "Cancel" (`.wl-button--text`, 44 px target, start-aligned) and "Save" (`.wl-button--primary`, full width, min 54 px, with the arrow icon). Save is the one primary action on this screen.

## Level group (D-0233 §1–§2)

- **Control:** a `<div role="radiogroup">` named "Level" (`aria-label`, the same naming as the Goal group above it; the sibling groups use short nouns). Not the UF-01.3 `.wl-segmented`; UF-01.3 keeps "Training experience" and its segmented control.
- **Rows:** three `<label class="wl-option">` rows, each holding a native `<input type="radio" name="level">` (visually hidden, in the tab order), the label text, the caption and the 2 px stroke tick icon (`aria-hidden`). Same anatomy as the Goal rows; the caption is the only addition.

| Label | Caption (hint) |
|---|---|
| Beginner | "Under 6 months. We start with form-first variations like the goblet squat." |
| Intermediate | "6 months to 2 years. Barbell basics plus targeted accessories." |
| Advanced | "2+ years. Adds the most demanding lifts, like the barbell deadlift." |

- **Label:** body text, weight 500, `--wl-ink` (unselected) or `--wl-on-selected` (selected). The radio's accessible name is the label only.
- **Caption:** under the label in the same row, caption style (13 px, weight 400, line height 1.4), wraps, never truncated. Colour by row state:
  - unselected: `--wl-ink-muted` on `--wl-bg`, 5.9:1;
  - hover (`--wl-raise` fill): `--wl-ink-on-raise`, 4.9:1 (`--wl-ink-muted` on `--wl-raise` is 4.2:1 and fails, so it is never used there);
  - selected (`--wl-selected` block): `--wl-on-selected`, 8.6:1.
- **Caption link:** each caption has its own id, and its radio has `aria-describedby` pointing at that id. A screen reader reads "Intermediate, radio button, 2 of 3, 6 months to 2 years. Barbell basics plus targeted accessories."
- **All three captions are visible at once.** Nothing changes in the text when the selection changes, so there is no live region and nothing to announce.
- **Level note:** directly under the group, one static `<p>` (caption style, `--wl-ink-muted`): "Level changes which exercises we suggest, not your targets." It has an id, and the radiogroup's `aria-describedby` names it. It is not a live region.
- **None of these is a live region:** the captions and the level note carry no `role="status"`, no `role="alert"` and no `aria-live`. The only status line on this screen stays the "Pick up to 3" line of the Priority areas group.
- **Initial value:** the user's stored level (`profiles.level`), read with the rest of the draft at the first read that finds a profile (D-0081 §2). A later cache refresh never overwrites the draft.
- **Effect on the screen:** picking a level changes no other block. The target preview stays the same (rule 4), which is what the level note says.
- **Keyboard:** Tab enters the group on the checked radio; arrow keys move and select (native radio behaviour); Tab leaves to the Rhythm group.
- **Target:** each whole row is at least 44 × 44 px; with the caption a row is about 64–84 px tall at 390 px.

## Save and Cancel

- **Dirty rule:** Save is enabled only when the draft differs from the baseline (goal, level, rhythm or priority areas) and the device is online. Picking Intermediate then Beginner again makes the draft equal to the baseline, and Save is disabled again.
- **Disabled look:** `aria-disabled="true"`, stays focusable and keeps its size; a tap does nothing.
- **What Save writes (D-0230 §2):**
  - only Level differs: one write, `profiles.update({ level })`. No target upsert, no check-in withdraw, so adapted targets and a pending check-in card survive;
  - goal, rhythm or priority areas differ (with or without Level): the D-0070 §3 three writes as today, with `level` in the `profiles` update.
  - Then the cache refresh, then the return (below).
- **While saving:** Save stays in place and is `aria-disabled`; a second tap does nothing.
- **Cancel** writes nothing and returns (below).
- **Return target (D-0230 §5, D-0233 §8):**
  - opened as `/plan/edit?from=favorites`: Save and Cancel go to `/plan/favorites`, and focus moves to the UF-11.6 title (`h1`, `tabindex="-1"`);
  - any other or missing `from` value (for example `?from=https://evil.example`): Save and Cancel go to `/plan`, with today's focus behaviour. No other value is honoured, so there is no open redirect.

## States

| State | What renders |
|---|---|
| Loading (first read pending) | The `h1` and the offline line only. |
| Cold cache (no plan on the device, offline) | The `h1`, the offline line, "Your plan isn't on this device yet. Connect to load it." (caption) and Cancel. No groups, no Save. |
| Ready, nothing changed | All blocks. Save `aria-disabled`. |
| Ready, a change made (online) | Save enabled. |
| Level only changed | Save enabled; the target preview is the same as before the change. |
| Offline | Same as ready. Every group stays usable (the draft is local). Save stays `aria-disabled` and "Connect to save" shows above Cancel and Save. When the connection returns, Save is enabled without a reload and the line goes. |
| Saving | Save `aria-disabled`; Cancel still navigates. |
| Save failed (online) | "Couldn't update your plan. Try again." (`role="alert"`) above Cancel and Save. The draft is kept, the screen stays, and the next tap on Save retries. |
| Arrived from UF-11.6 (`?from=favorites`) | Same as ready; only the return target differs. |
| Zero history, returning after 10 days off, time running out | No difference: everything here is profile and plan data. |

## Accessibility

- Heading outline: `h1` "Edit plan", then the `h2` "New targets per 14 days". The groups are named by `role` plus `aria-label` ("Goal", "Level", "Sessions per week", "Priority areas").
- Focus order follows the layout order: Goal, Level, the rhythm steppers, the chips, Cancel, Save.
- Single-choice groups are native radios in `radiogroup`s; the tick icon is `aria-hidden`, and the selected block plus tick is never colour alone.
- `aria-describedby`: each Level radio to its caption; the Level radiogroup to the level note.
- Live regions on this screen: the "Pick up to 3" status line and the save-failed alert. The Level captions and note are standing text.
- Focus ring: 2 px `--wl-focus`, 2 px offset, on every control (`--wl-on-selected` on the selected block, as in the Selected option row pattern).
- Targets: every row, stepper button, chip and button is at least 44 px tall; Save is 54 px.
- Contrast: `--wl-ink` on `--wl-bg` 8.6:1; `--wl-ink-muted` on `--wl-bg` 5.9:1; `--wl-ink-on-raise` on `--wl-raise` 4.9:1; `--wl-on-selected` on `--wl-selected` 8.6:1.
- Reflow: at 320 px captions wrap inside their rows and the chips wrap; no horizontal scroll.
- Not part of a workout: this is a Plan screen, not UF-09. No UF-09 control is added.
