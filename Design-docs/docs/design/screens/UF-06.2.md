# UF-06.2 Exercise history: Est. 1RM card, chart and table

- **Screen:** UF-06.2 Exercise history. Reached from UF-04.2 "My history" and from UF-06.1 Recent exercises. Nothing changes on UF-04.2, UF-02.1, UF-03.3, UF-06.1, UF-08 or UF-09.
- **Look:** Cobalt (D-0208), state `plan` (`[data-wl-state="plan"]`), plan background, no card fill behind the chart. Patterns in `components/state-patterns.md`. Font `--wl-font` (Familjen Grotesk).
- **Decisions:** D-0258 (wins on conflict), D-0256, D-0254, D-0255, D-0257, D-0211, D-0079 (rows and formats). Spec: `docs/specs/estimated-1rm.md`.
- **Tokens (only these, no new token, colour or font):** `--wl-action` (line and dots), `--wl-bg` (dot ring and page), `--wl-line` (gridlines), `--wl-ink-muted` (chart labels, captions, explanation). Text and numbers elsewhere keep the existing UF-06.2 classes and `--wl-ink`.
- **Superseded:** the prototype `UF06-2-History.dc.html` (Brzycki, "+19 kg in 12 weeks", a metric switch, retired fonts and colours) is superseded by this file. Do not build from it. The formula is plain Epley (D-0258 §1) and there is no metric switch.
- **Pattern:** this is the first chart in the app. Its rules (geometry, tokens, contrast, a11y, table alternative) are the pattern for later charts (D-0258 §15).

## Page order (top to bottom)

1. **title**: the exercise name, as today.
2. **caption**: "Last 8 weeks" (existing).
3. **offline line**: the existing offline status line, when offline.
4. **stat cards**: Best set, Heaviest, Sessions (existing) and **Est. 1RM** (new, fourth). The Est. 1RM card is hidden, with no "-" placeholder, when there is no valid point.
5. **delta line**: under the cards, two or more points only.
6. **chart**: 160 px tall, see Chart.
7. **table toggle**: "Show as table" / "Hide table", then the table when expanded.
8. **explanation**: one line under the toggle.
9. **session rows**: existing, newest first (D-0079 §9).
10. **how-to link**: existing.

## Est. 1RM card and delta line

- The card label is "Est. 1RM". The value is "about {N} kg", N the nearest whole kg (`formatWeight`), never a decimal and never without "about". Example: "about 124 kg".
- The delta line is a **plain paragraph** (not a live region), in `--wl-ink-muted`, under the cards. It compares the **latest point with the first point in the window**, in rounded kg. Words carry the direction, not colour or an arrow:
  - up: "Up 3 kg since 12 Oct"
  - down: "Down 2 kg since 12 Oct"
  - equal after rounding: "Same as 12 Oct"
- The date is "d MMM". With one point there is no delta line.

## Chart

Hand-written SVG in the feature, no library. One point per session (the best valid set, D-0254), unrounded in the data and rounded only for text.

| Part | Rule |
|---|---|
| Size | Height **160 px**. The viewBox width equals the container width. The chart scales with the page column; text stays inside the viewBox at 320 px and at 200 % zoom |
| Line | **2 px**, `--wl-action`, straight segments, `vector-effect: non-scaling-stroke`. Drawn only with two or more points |
| Dots | **6 px** diameter, `--wl-action`, with a **2 px `--wl-bg` ring** so a dot reads over the line |
| Gridlines | **1 px**, `--wl-line`, `vector-effect: non-scaling-stroke`. **2 or 3** lines, each labelled "{N} kg" in `--wl-ink-muted` |
| y axis | From a **rounded floor** below the lowest point to a **rounded ceiling** above the highest. Not from zero: the trend is the point |
| x axis | **Time-proportional** over the local dates: a 10-day gap looks like a gap. Only the first and last dates are labelled, "d MMM" (for example "12 Oct"), in `--wl-ink-muted` |
| Latest label | Text next to the latest dot, "about {N} kg", with `text-anchor: end` near the right edge. If it would collide with the line, a dot or a gridline label, it flips **below** the dot |
| 320 px | Reserve **36 px left** (gridline labels) and **16 px right** |
| Motion | None. The chart draws once, also with reduced motion off |
| Interaction | None in v1: the dots are not tappable, so no hit area is needed |

- **Same-day sessions:** two sessions on one local date keep both points at the **same x**, drawn as a **vertical step**. The table has one row for each (D-0258 §5).
- **Never colour only:** the latest point has its text label, the card repeats the value, and the delta line says the direction in words.
- **Contrast line.** Gridlines are decorative, `--wl-line` on `--wl-bg` is 2.1:1 (D-0211 §4). All chart text, `--wl-ink-muted` on `--wl-bg`, is at least 4.5:1. The line and the dots, `--wl-action` on `--wl-bg`, are at least 3:1. The design-tokens test computes these from `tokens.json`.

## Accessibility

- The SVG has `role="img"` and an `aria-label` summary: "Estimated one-rep max, 5 sessions, from about 118 kg on 12 Oct to about 124 kg on 18 Nov." (count, first and last value and date).
- Every `<text>` inside the SVG is `aria-hidden` (`aria-hidden="true"`) so it is not read twice. The delta line is a plain paragraph, not a live region.
- Touch targets at least 44 px. Focus ring is the generic `--wl-focus`.
- Zoom to 200 %: card text and table wrap, the chart scales.

## Table alternative

- **Toggle:** a `<button>` directly under the chart, at least **44 px** tall, labelled "Show as table" and, when open, "Hide table". It has `aria-expanded` and `aria-controls` pointing at the table's container.
- **Table:** a real `<table>`, rendered **only when expanded**, caption "Estimated 1RM per session". Columns: **Date** (each cell is a row header, `scope="row"`), **Best set** ("100 kg x 8"), **Est. 1RM** ("about 127 kg"). One row per point, **oldest first**. Dates "d MMM".
- The chart stays visible when the table is open. **Focus stays on the toggle** when it opens and closes. No animation.

## States

| State | What shows |
|---|---|
| Zero history | The existing "no sets" line. No Est. 1RM card, no chart, no toggle, no explanation |
| None valid (all sets above 10 reps, or all weight 0) | Existing cards and rows. The Est. 1RM card is hidden. In place of the chart: "No estimate yet. Estimates need a weighted set of 1–10 reps." No toggle, no explanation |
| Bodyweight or timed | One line: "Estimated 1RM is for weighted lifts." Existing cards unchanged. No Est. 1RM card, chart or toggle |
| One point | The card with its value. The chart shows one dot with its label and no line, and under it: "One session so far. Log it again to see a trend." No delta line. The toggle and table work with one row |
| Two or more points | Card, delta line, chart, toggle, explanation |
| Returning after 10 days off | Nothing special. The gap shows on the x axis and a lower point after a break is drawn as is |
| Offline | Identical. The screen reads the cache and the queue, so values equal the online ones. The existing offline status line stays |
| Partial cache | As existing (D-0079): the chart waits with the cards. No skeleton |
| Same-day sessions | Both points at the same x, a vertical step. One table row each. The delta compares the last point with the first |

A session older than 56 days is not plotted. Not reachable during a workout (UF-08, UF-09 never show it).
