# UF-09.9 Paused: the actions, "Do {name} later" and "Add exercise"

- **Screen:** UF-09.9 Paused. This file specifies the layout, the combined action list, "Do {name} later", "Add exercise" and the status line; the stats and the End confirm are unchanged (prototype `prototype/UF09-9-Pause.dc.html`).
- **Decisions:** D-0243 §1 (Add exercise), D-0247 §1 (the sheet is a host overlay; Back through `closeForBack()`), D-0246 §6 §7 (Back and Escape, focus, status line, no remount), D-0205 (§11, Do later), D-0120 (§1 §6–§8), D-0111 (§7), D-0203. Specs: `docs/specs/add-exercise-in-session.md`, `docs/specs/uf-08-add-and-reorder.md`. The sheet it opens: `UF-09.10.md`.
- **Look:** Cobalt + state colour (D-0208); state `plan`; patterns in `components/state-patterns.md`. Familjen Grotesk through `--wl-font`.
- **Principle 1:** nothing is added to focus mode (UF-09.1 to UF-09.8). The only in-workout controls are on this screen, behind Pause.
- **Tokens:** existing only; action rows are hairline rows (`.wl-row`: transparent, a 1 px `--wl-line` hairline, `--wl-ink`). No new token, no hex.

## Layout (top to bottom)

1. Caption "Workout paused · timers stopped" (label role, `--wl-ink-muted`).
2. Title "Paused" (`h1`, page title role).
3. Numbers: Elapsed, Left, Sets (D-0120 §6), unchanged.
4. Failure strip, only after a failed Do later: "Couldn't move {name}. Try again." (`role="alert"`, `--wl-ink` on a `--wl-raise` strip).
5. **Resume**, the only primary button (session button in the lift colour).
6. The action rows, in the order of the action table below.
7. **Status line:** one `role="status"` line, **present and empty on mount** (an empty live region takes no height and is never `display: none`). After a successful add it reads **"{name} added after {current name}."** ({name} the added exercise, {current name} the current exercise, the one the add went after). Label role, `--wl-ink` on `plan.bg` (8.6:1), left-aligned, wraps. It is the only success line: there is no "{name} added." variant, because the insert is always after the current exercise (D-0246 §4). The next add replaces it, and it goes when the pause ends. After a successful add, focus is on "Add exercise". Paused **does not remount** when the sheet opens, when it closes, or when the plan changes after an add (D-0246 §7), so the line and focus survive.
8. **End workout**, the secondary outline, last (destructive actions sit last). Confirms in place (D-0120 §8).

Item 4 and item 7 are different lines: the Do later failure is an alert from this screen; the add result is the status line. The sheet's own refusals and its failed-write alert stay on the sheet (`UF-09.10.md`).

## "Add exercise" (D-0243 §1, D-0246 §6 §7)

- **Label:** "Add exercise", unique on the screen. The "+" is a 22 px 2 px stroke glyph, `aria-hidden`, so the accessible name is the label alone. The button carries `aria-haspopup="dialog"`.
- **Shown** in every paused phase: `getReady`, `warmup`, `set`, `confirm`, `rest`, `timed` and `next` (a pause from UF-09.6, where the add lands after the exercise about to start).
- **Hidden** (not in the DOM, no gap) only when the pause came from UF-09.8 Time check (`resumePhase: "timeCheck"`): that screen has its own options, and being behind leaves no time to add anything.
- **Still shown at 8 items and with no time left.** The action never disappears silently: the sheet explains why nothing can be added (its lead line "No time left", its refusal lines).
- **Tap:** opens UF-09.10 as a **host overlay over this screen** (D-0247 §1). Unlike the Swap, How-to and List view seam overlays, which replace Paused, the sheet leaves Paused mounted underneath; the pause is unchanged and every timer stays stopped.
- **After a successful add:** the sheet closes, the screen is still UF-09.9, the status line (item 7) reads "{name} added after {current name}." and focus is on "Add exercise". The user may add another, or Resume.
- **After Close, Escape or Back on the sheet:** the sheet closes, focus is on "Add exercise", the workout is still paused, nothing is announced. Back goes through the host's `closeForBack()`, which closes only the sheet and pushes the Back guard again (D-0247 §1); Back on Paused with no overlay open still leaves the session (D-0163 §1).
- **Offline:** identical; the plan write is queued.

## "Do {name} later"

- **Label:** "Do {name} later", {name} the current exercise (for example "Do Inverted row later"), unique on the screen.
- **Current item:** the item at `itemIndex`, or item 0 when the pause came from Get ready or Warm-up.

### When it is hidden (not in the DOM, no gap)

- The current item is partly done: it has any logged set (from focus mode or the List view).
- The current item is the last unfinished item: no later item is neither complete nor skipped.
- The current item is already skipped.
- The pause came from UF-09.8 Time check.

### Effect and feedback

- The item moves to just after the next item that is neither complete nor skipped. One tap, no confirm.
- The pause ends. From Get ready or Warm-up the same phase resumes; otherwise UF-09.6 Next exercise opens for the new current item with its 60 s set-up countdown. A `role="status"` line (present on mount) on UF-09.6 says "{name} moved to later."
- No UF-09.8 check runs. Elapsed and Left on the pause are unchanged.
- **Failure:** "Couldn't move {name}. Try again." (layout item 4). The pause and order are unchanged.
- **Offline:** identical; the change is queued.
- **Repeat:** the action on the new current item pushes that one on. There is no "Move to end" in v1.
- **To do an added exercise now:** when the current exercise isn't started, "Do {name} later" on it puts the added one first (D-0246 §5).
- **Focus:** the pause screen unmounts; the next screen follows its own focus rule. On failure focus stays on the action.

## Focus

- On first entry: Resume (D-0120 §8). While the End question shows: Cancel.
- After the sheet closes, by a successful add or by Close, Escape or Back: "Add exercise".
- Focus never drops to `body`.

## Accessibility

- Every target at least 44 px (rows 56 px), labels unique, focus ring 2 px `--wl-focus`, offset 2 px (inset on full-width rows). Contrast: `--wl-ink` on `plan.bg` 8.6:1; glyphs `--wl-ink-muted` 5.9:1 (needs 3:1); the alert strip `--wl-ink` on `--wl-raise` 6.2:1.
- One `role="status"` line on this screen, present and empty on mount; the sheet is modal, so only one live surface at a time. The End confirm replaces the action list and keeps its own `aria-live` failure line.
- Build: web-feature:UF-09 (T-0578, T-0579 for Do later; T-0949 for Add exercise and the status line).
