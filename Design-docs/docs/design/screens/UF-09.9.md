# UF-09.9 Paused: "Do {name} later"

- **Screen:** UF-09.9 Paused. Only the new action is specified; the rest is unchanged (prototype `prototype/UF09-9-Pause.dc.html`).
- **Decisions:** D-0205 (§11), D-0120 (§1 §7), D-0111 (§7), D-0203. Spec: `docs/specs/uf-08-add-and-reorder.md`.
- **Principle 1:** nothing is added to focus mode (UF-09.1 to UF-09.8). The only in-workout control is on this screen, behind Pause.
- **Tokens:** existing only; the action uses the pause action-row style (surface card, 1 px `line` border, `text`). No new token, no hex.

## Placement

The action list reads: Swap this exercise, **Do {name} later**, Skip to next exercise, How to do {name}, Show full list view. Same row class as its neighbours: min 56 px tall (at least 44 px), 22 px icon with 2 px stroke (a "move later" chevron-down arrow, `aria-hidden`), label wraps and is never truncated at 320 px. Resume stays the only primary button.

- **Label:** "Do {name} later", {name} the current exercise (for example "Do Inverted row later"), unique on the screen.
- **Current item:** the item at `itemIndex`, or item 0 when the pause came from Get ready or Warm-up.

## When it is hidden (not in the DOM, no gap)

- The current item is partly done: it has any logged set (from focus mode or the List view).
- The current item is the last unfinished item: no later item is neither complete nor skipped.
- The current item is already skipped.
- The pause came from UF-09.8 Time check.

## Effect and feedback

- The item moves to just after the next item that is neither complete nor skipped. One tap, no confirm.
- The pause ends. From Get ready or Warm-up the same phase resumes; otherwise UF-09.6 Next exercise opens for the new current item with its 60 s set-up countdown. A `role="status"` line (present on mount) on UF-09.6 says "{name} moved to later."
- No UF-09.8 check runs. Elapsed and Left on the pause are unchanged.
- **Failure:** "Couldn't move {name}. Try again." (`role="alert"`, `text`, `surface-2` strip above the action list). The pause and order are unchanged.
- **Offline:** identical; the change is queued.
- **Repeat:** the action on the new current item pushes that one on. There is no "Move to end" in v1.
- **Focus:** the pause screen unmounts; the next screen follows its own focus rule. On failure focus stays on the action.

## Accessibility

- Target at least 44 px, label unique, focus ring 2 px `accent`, offset 2 px. Contrast as the other action rows.
- Build: web-feature:UF-09 (T-0578, T-0579).
