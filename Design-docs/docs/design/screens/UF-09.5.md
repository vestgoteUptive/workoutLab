# UF-09.5 Rest: the "Next" block names what is next (D-0273)

- **Screen:** UF-09.5 Rest (prototype `prototype/`, otherwise unchanged). Related: UF-09.3 Current set (same per-side wording) and UF-09.6 Next exercise (shows the cue again one step later).
- **Decisions:** D-0273 (this spec's source), D-0261 and D-0263 §4 §8 (per-side wording), D-0208 (Cobalt rest state), D-0118 §7 (the "Next" line). Spec: `docs/specs/rest-next-exercise.md`.
- **Look:** Cobalt rest state (`[data-wl-state="rest"]`, draining to lift). **No new token, role or font is used.** Every colour is `--wl-ink` or `--wl-on-action`; every size is an existing role, except one size choice for the per-side unit span (below). Session font (Bricolage Grotesque).
- **Principle 1:** Rest stays the task. The block is read-only text: no button, link, picture or step. Pause, −15 s, +15 s and Skip rest are unchanged.

## The Next block

A column under −15 s / +15 s and above Skip rest, up to four lines in this order. When nothing follows, the block is absent.

| # | Line | Type role | Colour | Wrapping | When |
|---|---|---|---|---|---|
| 1 | Caption | label role (0.9375rem, 600) | `--wl-ink` | wraps | always when something follows |
| 2 | Exercise name | 1.5rem (24 px), 700, line height 1.15, `overflow-wrap: anywhere` | `--wl-ink` | wraps, never truncated | always when something follows |
| 3a | Load line | stat role (3.5rem, 800), unit span 1.5rem | `--wl-ink` | wraps, never truncated | next set of the same exercise, reps set |
| 3b | Cue | body role (1.0625rem / 1.45) | `--wl-ink` | wraps, never truncated | next set starts a new exercise |

- Lines 3a and 3b never appear together. The gap between lines is 0.25rem; the block starts 1.75rem under the −15 s / +15 s row (as today).
- **Hierarchy:** timer (hero number) > load (stat) > name (1.5rem) > caption and cue (label, body). The name never competes with the timer: the timer is about 5 times its size at 320 px.
- **Colour:** `--wl-ink` only. The rest state defines no `ink-muted` key, so `--wl-ink-muted` would resolve to the same white; the spec names `--wl-ink` so nothing relies on that fallback.
- **Unit span:** the flagged suffix (" per arm") sits in the `.wl-uf09__unit` span. That rule is scoped to the lift state today; the rest state needs its own rule, `font-size: 1.5rem; letter-spacing: 0` (the same size as the name, so it reads as part of the load, not as a new line). A CSS size only, no token.
- **Not a live region:** no `role`, no `aria-live`. The block is read in order with the screen. The timer and the chrome announcer stay the only live things.

## 320 px and 200 % zoom

- Every line wraps. No `text-overflow`, no `line-clamp`, no fixed height, no truncation anywhere in the block. Long names wrap on word breaks and, if a word is too long, anywhere (`overflow-wrap: anywhere`).
- The page scrolls (`min-height: 100dvh`, no fixed or sticky footer). **Skip rest stays reachable** by scrolling at 320 px and at 200 % zoom, and it still takes focus on mount, which scrolls it into view. The timer keeps its order and its clamped size (`clamp(5rem, 36vw, 9.375rem)`); the targets stay at least 44 px (Skip rest 64 px, −15 s / +15 s 48 px).
- **Worst case on one phone height, 320 × 568** (estimate from the CSS; line heights summed, 24 px page padding top and bottom): chrome 68, "Rest" title 45, timer 138 (115 px at 0.85), −15 s / +15 s 72, so 323 px before the block. Longest library name is 29 characters ("Standing calf raise (machine)"): two lines at 288 px, 55 px.

| Case | Block height | Skip rest top | Scrolls? | Visible without scrolling |
|---|---|---|---|---|
| New exercise, 45-character cue (2 lines) | about 162 | about 533 | by about 53 px | title, timer, ±15 s, caption, name, cue, the top of Skip rest (35 px of 64) |
| Same exercise, not flagged, load on one line | about 168 | about 539 | by about 60 px | as above with the load line; Skip rest top edge only |
| Same exercise, flagged, load wrapped to three lines | about 254 | about 625 | by about 145 px | title, timer, ±15 s, caption, name, most of the load; Skip rest below the fold |

- The first two fit within about 60 px of one screen; the third (flagged, long name, wrapped load) scrolls about a quarter of a screen more. This is accepted (D-0273 Consequences): the load must stay the larger line, so it is not shrunk to save height. Skip rest is focused on mount, so the browser brings it into view without a swipe for keyboard and switch users.
- Cue and flagged load never share a screen (3a and 3b are exclusive), so the "flagged load plus 45-character cue" pair in the worst case cannot occur; each half is in the table. The e2e check (T-0991) measures the real heights at 320 × 568 and at 200 % zoom; if Skip rest is not reachable there, that is a bug against this spec.

## Copy

| Where | Text |
|---|---|
| Caption, same exercise | "Next · set 3 of 4"; "Next · back-off set" for a back-off |
| Caption, new exercise | "Next exercise" (`en.uf09.titles.next`; replaces "Next · {name}") |
| Name | the library name, e.g. "Dumbbell row" |
| Load, not flagged | "27,5 kg × 10" |
| Load, flagged | "27,5 kg × 10 per arm" ("27,5 kg × 10" plus the unit span " per arm") |
| Load, flagged, hidden reading | "27,5 kg, 10 reps per arm" (visually-hidden span; the visible lines are `aria-hidden`) |
| Bodyweight, not flagged | "10 reps" |
| Bodyweight, flagged | "10 reps per arm" |
| Weight unknown ("Set weight") | "Set weight" over "× 10", or over "× 10 per arm" when flagged |
| Cue | the library cue, e.g. "Lead with the elbows, stop at shoulder height" |

- The suffix words (" per arm", " per leg", " per side") and the hidden reading come **only from `apps/web/src/lib/i18n/per-side.ts`** (`perSide`, `readReps`, D-0263 §8). The rest screen keeps no copy of them.
- Cue source: the cached `cue`; if missing or empty, the first line of the cached how-to (`instructions[0]`); if neither, no line. A rejected or missing cache read gives no line and no error. Library text only, never LLM text.
- Numbers use the locale decimal ("27,5").

## States

| State | What the Next block shows |
|---|---|
| Same exercise next | Caption "Next · set 3 of 4", name "Bench press", load "27,5 kg × 10". No cue. |
| New exercise next | Caption "Next exercise", name "Dumbbell row", cue. No load line, no sets summary. |
| Last set, nothing next | No rest follows the last set of the last exercise, so the screen does not appear. A rest with nothing after it (started from the List view): no Next block, no name, no empty caption. Rest, timer, ±15 s, Skip rest as today. |
| One-side, flagged | Same exercise next: load reads "× 10 per arm" (or leg or side) with the hidden reading. New exercise next: name and cue only, no reps to label. |
| One-side, not flagged | Exactly as above without the suffix and hidden reading. |
| Cue present | Cue line under the name. |
| Cue absent | No cue line, no empty space, no message. |
| Timed | Same exercise next: caption and name, no load line (hold target shows on UF-09.7). New timed exercise: name and cue. No stepper, no "Hold 0:40". |
| Offline | Identical. Name from the loaded library; cue and flag from the cache. An uncached detail: name and load, no cue, no suffix (reads as both sides), no message. |
| 10 days off | Nothing changes: the load is the engine's re-entry pre-fill; name and cue are the same. |
| Zero history | "Set weight" over the reps; the name still sits above it. A first rest after set 1 shows the name with no history. |
| At 0 (GO) | "GO" shows as today; the Next block stays until the machine moves on. |

Binary pairs, all stated: flagged and not flagged (rows 4 and 5), cue present and absent (rows 6 and 7), online and offline (row 9), same exercise and new exercise (rows 1 and 2).

## First frame

- **First paint:** caption, name, load and the per-side word. The name is from `ctx.library`; the word comes from the T-0979 first-frame store through `useCachedFields`.
- **After first paint:** the cue (its own IndexedDB read). It is the last line of the block with Skip rest below it, so a late cue moves Skip rest down and nothing above it. Reserve nothing: an absent cue must leave no gap. If the move is seen in use, add the cue to the first-frame store (a web-shell change, parked in D-0273).

## Out of scope

Sets × reps summary, picture, mistakes, how-to link or "see more" on rest; anything about the exercise after next; the cue on a same-exercise rest; the timed hold target; voice or sound; changes to UF-09.6 or to the rest lengths. No token, role or font changes.
