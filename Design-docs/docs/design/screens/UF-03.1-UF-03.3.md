# UF-03.1 Active and UF-03.3 Summary: "per arm" on set rows

- **Screens:** UF-03.1 Active (the list view's set rows) and UF-03.3 Summary (the PR line and set rows). A short note only; the screens are otherwise unchanged.
- **Decisions:** D-0261, D-0263 §6 and §8. Spec: `docs/specs/unilateral-exercises.md`.
- **Look:** Cobalt (D-0208). No new token, colour or font.

## One side at a time (D-0261, D-0263 §6)

- **Applies to** a flagged exercise (`unilateral` is `arm`, `leg` or `side`). A row that is not flagged is unchanged, exactly as today.
- The suffix is appended to the screen's existing format. All strings come from `formatReps` and `perSide` (see `UF-09.3-UF-09.4.md`); `SummaryContent` (`prText`, `prReps`, `prWeighted`) and `ListView` call it, none keeps its own copy.

| Place | Flagged format | Example |
|---|---|---|
| Weighted set row | "{weight} × {reps} per arm" | "12 × 10 per arm" |
| Bodyweight set row | "{reps} per arm" | "10 per arm" |
| Timed set row | "{s} s per side" | "40 s per side" |
| ListView `repsLabel` (accessible name) | "Set {n} reps per arm" | "Set 2 reps per arm" |
| PR band line (weighted) | "{name} {weight} × {reps} per arm" | "Dumbbell Row 12 kg × 10 per arm" |
| Grouped summary row | "3 × 10 per arm · 12 kg" | "3 × 10 per arm · 12 kg" |

- **Grouped form:** "3 × 10 per arm · 12 kg" is used only where a grouped row already exists. Other rows use the per-set formats above.
- **Worked example:** 10, 10, 9 at 12 kg on a dumbbell row. Rows: "12 × 10 per arm", "12 × 10 per arm", "12 × 9 per arm". ListView names: "Set 1 reps per arm", "Set 2 reps per arm", "Set 3 reps per arm".
- The UF-03.1 reps stepper keeps its names; the visible count and caption follow `UF-09.3-UF-09.4.md`.
- The suffix wraps at 320 px and never truncates. Contrast: the suffix uses the same colour as the row text, so contrast is as today.
- **Offline:** the flag comes from the cached library; queued sets are plain reps and weight, so rows read the same.
- Coverage, targets and balance are unchanged: one set is one hard set.

Build: `web-feature:UF-03` after this spec.
