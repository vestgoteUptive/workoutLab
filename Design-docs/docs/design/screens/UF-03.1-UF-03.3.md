# UF-03.1 Active and UF-03.3 Summary: "per arm" on set rows

- **Screens:** UF-03.1 Active (the list view's set rows) and UF-03.3 Summary (the PR line and set rows). A short note only; the screens are otherwise unchanged.
- **Decisions:** D-0261, D-0263 §6 and §8. Spec: `docs/specs/unilateral-exercises.md`.
- **Look:** Cobalt (D-0208). No new token, colour or font.

## One side at a time (D-0261, D-0263 §6)

- **Applies to** a flagged exercise (`unilateral` is `arm`, `leg` or `side`). A row that is not flagged is unchanged, exactly as today.
- The suffix is added to the screen's existing format. All strings come from `formatReps` and `perSide` (see `UF-09.3-UF-09.4.md`); `SummaryContent` and `ListView` call them, none keeps its own copy.

| Place | Flagged format | Example |
|---|---|---|
| ListView reps input (aria-label only, no visible suffix) | "Set {n} reps per arm" | "Set 2 reps per arm" |
| ListView seconds input (aria-label only) | "Set {n} seconds per side" | "Set 2 seconds per side" |
| ListView previous session, `previousLoad` | "{kg} × {reps} per arm" | "97.5 × 8 per arm" |
| ListView previous session, `previousReps` | "{reps} reps per arm" | "8 reps per arm" |
| ListView previous session, `previousSeconds` | "{s} s per side" | "40 s per side" |
| Set row, weighted | "{weight} × {reps} per arm" | "12 × 10 per arm" |
| Set row, bodyweight | "{reps} per arm" | "10 per arm" |
| PR line, `prWeighted` | "{name} {weight} × {reps} per arm" | "Dumbbell Row 12 kg × 10 per arm" |
| PR line, `prReps` | "{name} {reps} reps per arm" | "Push-up 25 reps per arm" |
| PR line, `prTimed` | "{name} {s} s per side" | "Side plank 40 s per side" |

- **ListView inputs** change their aria-label only: there is no visible suffix next to the input. A timed hold is edited here (UF-09 has no stepper for timed holds).
- **No grouped summary row:** none exists today, so the "3 × 10 per arm · 12 kg" form is not used. Every set has its own row.
- **Worked example:** 10, 10, 9 at 12 kg on a dumbbell row. Rows: "12 × 10 per arm", "12 × 10 per arm", "12 × 9 per arm". Input names: "Set 1 reps per arm", "Set 2 reps per arm", "Set 3 reps per arm".
- The suffix wraps at 320 px and never truncates. Contrast: the suffix uses the same colour as the row text, so contrast is as today.
- **Offline:** the flag comes from the cached library; queued sets are plain reps and weight, so rows read the same.
- Coverage, targets and balance are unchanged: one set is one hard set.
- UF-02 Today shows the same PR lines through the same helper (T-0975).
