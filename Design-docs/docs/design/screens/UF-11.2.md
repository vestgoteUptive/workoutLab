# UF-11.2 Plan: Excluded exercises row

- **Screen:** UF-11.2 Plan. Only the new row is specified here. Everything else on the screen is unchanged.
- **Decisions:** D-0199 (§10 design). Links to `UF-11.5.md`.
- **Tokens:** `surface`, `line`, `text`, `text-muted`.

## Layout

- A row directly **under the priority areas** and above the per-area targets. It is a link (`<a href="/plan/excluded">`), the whole row is the target, at least 56 px tall and full width. A `surface` card with a 1 px `line` border.
- Text "Excluded exercises" (DM Sans 700, 16 px, `text`) followed by the count part, with a 2 px stroke chevron icon at the right edge.
- Visible text: "Excluded exercises · 2" with n at least 1, and "Excluded exercises · none" when the list is empty. `text-muted` for the "· 2" or "· none" part.
- The count is the stored list size, from this user's cache.

## States

| State | Row |
|---|---|
| Non-empty (n at least 1) | "Excluded exercises · 2" |
| Empty | "Excluded exercises · none". The row stays a link; UF-11.5 shows its empty state |
| Offline | Same as online. The row only navigates; it is not a write control, so it is not disabled |
| Loading, first run, no cache | "Excluded exercises" with no count until the first read resolves; no "none" is shown before then (D-0197 §2: only an authenticated empty read means none) |
| Count changes on return from UF-11.5 | The row shows the new count when UF-11.2 renders again |

## Accessibility

- Accessible name: "Excluded exercises, 2" or "Excluded exercises, none". The chevron is `aria-hidden`.
- Focus ring 2 px `accent`, offset 2 px. Target at least 44 px (the row is 56 px).
- Never shown on UF-03, UF-08 or UF-09. No UF-09 control is added.
