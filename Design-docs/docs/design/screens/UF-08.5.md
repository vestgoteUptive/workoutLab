# UF-08.5 Add exercise

- **Screen:** UF-08.5 Add exercise, a sheet over **UF-08.6 Area detail** (`UF-08.6.md`; amended by D-0274 §5, it was a sheet over the exercise-list UF-08.2). The UF-08.3 pattern: no URL change. Never reachable from UF-02, UF-03 or UF-11. During a workout the same list opens as **UF-09.10 Add exercise**, a sheet over focus mode reached only from UF-09.9 Paused (D-0243, which amends D-0205 §1); `UF-09.10.md` lists how its rows and lead line differ from this sheet.
- **Decisions:** D-0243 (UF-09.10 reuses this sheet in a workout), D-0231 §1 (row 4 copy, text only), D-0205 (§11), D-0203, D-0202 (Favorite tag), D-0199 (excluded list), D-0191, D-0109. Spec: `docs/specs/uf-08-add-and-reorder.md`. Modelled on `UF-08.3-UF-05.1.md` and `UF-11.6.md`; where this file is silent, those apply.
- **Look:** Cobalt + state colour (D-0208); state `plan`; patterns in `components/state-patterns.md`.
- **Type:** Familjen Grotesk through `--wl-font` (the plan font, `--wl-font-plan`), in the plan roles of `design-system.md`. Sentence case; no uppercase transforms.
- **Foundation classes (D-0203, as amended by D-0208):** `.wl-row` (hairline rows: 12 px vertical padding, a 1 px `--wl-line` bottom hairline, no fill and no border box) and `.wl-label`. No cards: structure comes from hairlines and type size (D-0208). Tokens: existing only (`--wl-bg`, `--wl-raise`, `--wl-line`, `--wl-ink-muted`, `--wl-ink`, `--wl-focus`). No new token, no hex. Components: Favorite tag pill (see `UF-08.2.md`), neutral notice.

## Layout (full-height sheet, 320 px and 390 px wide, top to bottom)

1. Header: title "Add exercise" (`h2`, Familjen Grotesk through `--wl-font`, section title role, sentence case) and **Close** (44 px target, top right).
2. Lead line, `--wl-ink-muted`. Suggested mode: "The rest of your workout adjusts to fit {n} min." In empty mode (UF-08.2 opened by "Start empty", D-0236, `UF-08.2.md` › Empty mode) it reads "{left} of {n} min left." instead, where `{left}` is the UF-08.2 budget line's `left` (`unusedS` rounded down): an Add there places only that exercise, so nothing else adjusts. **Amended by D-0274 §5:** the suggested-mode line is **retired by D-0274**, and the empty-mode line is now the only one: opened from UF-08.6, an Add is local, so the lead line is always "{left} of {n} min left." (`{left}` is the minutes the plan still has). There is one mode.
3. Search field, visible label "Search exercises", `type="search"`, 48 px tall, `--wl-ink-muted` 1 px border, `--wl-raise` fill, a 44 px clear button when it has text. **Focused on open.**
4. Status line, `role="status"`, present on mount, empty until used. It holds the Add result ("{name} added." is announced on UF-08.6) and the refusal text below.
5. The list: sections with an empty query, results with a query.

At 320 px nothing scrolls sideways; names and area lines wrap, never truncate. The sheet body scrolls; header and search stay visible.

## Empty query

The list is **area first** (D-0274 §5, opened from UF-08.6 for area {A}):

1. **Favorites** (`h2`, `.wl-label`): stored favorites, by name then id, one hairline list. Omitted when there are none.
2. **{A}** (the open area, `h2`, `.wl-label`): the area's other exercises (weight 1.0 in {A}, by name then id), not repeated from Favorites and not already in the plan. Omitted when empty.
3. **Today's areas** (below):

   **Today's areas**: one hairline list per area of a current item in the fixed area order (chest, back, shoulders, arms, core, glutes, quads, hamstrings, calves), each with the area as an `h2` in `.wl-label`. Inside: exercises with weight 1.0 in that area, by name then id. An exercise already shown under Favorites is not repeated. Each section is a `<section aria-labelledby>`.
4. **No items (all removed):** Favorites only, then "Search to find an exercise." (`--wl-ink-muted`, centred). With neither: only that line.
5. Warm-up moves never appear. Each exercise can appear under several areas; the Add button's accessible name then ends with the area: "Add {name}, {area}". Otherwise "Add {name}".

## Query

A flat list of hairline rows: case-insensitive substring of the name over every exercise, by name then id. No match: "No exercises match “{query}”." (`--wl-ink-muted`, centred). No section headings.

## Result row

- A `.wl-row` hairline row, min 64 px, wraps. Line 1: name (Familjen Grotesk through `--wl-font`, row title role: 1.0625 rem, 600, `--wl-ink`) and, for a favorite, the "Favorite" tag after it (same pill as UF-08.2). Line 2: primary areas ("Back, Quads", `--wl-ink-muted`, 13 px). Line 3 (only when disabled): the reason line (`--wl-ink-muted`, 13 px).
- Actions below the text, in a wrapping group with 8 px gaps, each at least 44 px tall and 96 px wide:
  - **Add** (secondary: `--wl-ink-muted` border, `--wl-ink`). Accessible name "Add {name}".
  - **Start with this** (secondary), compound exercises only. Accessible name "Start with {name}". Not shown for isolation exercises.
- Add is a secondary button on purpose: the sheet has no primary action.

## Disabled rows

The first match wins; the text is the only signal (no colour, no icon). Disabled buttons keep their size, stay focusable, are dimmed (`--wl-ink-muted` text), have `aria-disabled="true"` and `aria-describedby` pointing at the row's reason line.

| Order | Reason line | Add | Start with this |
|---|---|---|---|
| 1 | "In this workout" | disabled | enabled if a non-main compound; absent if the main lift or an isolation |
| 2 | "Excluded. Include it again in Plan › Excluded exercises." | disabled | disabled |
| 3 | "Not available with your equipment" | disabled | disabled |
| 4 | "Above your level. Change it in Plan › Edit plan." | disabled | disabled |
| 5 | "Skipping {Area} today" | disabled | disabled |
| 6 | "{Area} is recovering" | disabled | disabled |

An exercise removed on this visit is not disabled. The sheet never writes the excluded list or the level; rows 2 and 4 only say where to do it, in plain text with no link and no button (D-0205, D-0231 §1). Leaving UF-08 would discard the setup visit (D-0109), so the sheet never navigates to Plan. The row 2 and row 4 pointers are this sheet's only: No UF-09 control is added (D-0231), and UF-09.10 shows the short "Excluded" and "Above your level" lines with no pointer.

## Refusal status line

When Add or Start with this does not fit, the sheet stays open and the status line (a `--wl-raise` neutral notice with the 2 px info icon, directly under the search field, `role="status"`) says one of:

- "This workout has 8 exercises, the most it can hold."
- "This workout already has two {Area} exercises."
- "{name} doesn't fit in {n} min. Start with it instead, or pick more time." (compound, Add)
- "{name} doesn't fit in {n} min. Pick more time." (isolation, or Start with this)

Two more refusals, in the order of `UF-08.2.md` › Empty mode › Refusals (D-0239 §13, D-0240 §4): while the plan is over budget (either mode), "Your workout is {over} min over. Remove or swap an exercise first." comes before the lines above; in empty mode, when the new item fits but pushes out a pick or the main lift, "{name} would push out {pick}. Pick more time or remove an exercise." comes after them.

The text clears on the next attempt or when the sheet closes. Not the attention colour. Focus stays on the button used.

## States and focus

| State | What shows |
|---|---|
| Online / offline | Identical. Search, Add and Start with this run on the device from the cached library, favorites and excluded list. No offline state, no offline line |
| Empty query, plan and favorites | Both sections |
| Empty query, no favorites | "Today's areas" only |
| Empty query, no items | Favorites only, then "Search to find an exercise." |
| Query with matches / without | Flat list / "No exercises match “{query}”." |
| Refused | Sheet open, refusal in the status line |
| Success | Sheet closes, focus on the new row's Swap button on UF-08.6 (an Add of another area adds that area and stays on UF-08.6: "{name} added. {Area} is in your plan now.") |

Close, Escape and browser Back close the sheet without a change and return focus to the "Add exercise" button on UF-08.6. The sheet traps focus while open. Focus ring 2 px `--wl-focus`, offset 2 px.

## Accessibility

- Dialog `role="dialog"`, `aria-modal`, labelled by "Add exercise". Search is labelled, not placeholder only.
- Names unique per row: "Add {name}", "Start with {name}"; the visible text starts the name (WCAG 2.5.3).
- Targets at least 44 px (WCAG 2.5.8). `--wl-ink-muted` on `plan.bg` 5.9:1; text on `--wl-raise` uses `--wl-ink`, 6.2:1.
- The status line is present on mount. The disabled reason is read with the button through `aria-describedby`.
- Build: web-feature:UF-08 (T-0573 to T-0577).

It is still a pin for this visit, so a time rebuild keeps it. An exercise whose area is not in the plan adds that area.
- **Retired by D-0274:** the suggested-mode lead line and the empty-mode sheet variants tied to a Suggestions section; "Start with this" and the refusals stay as written (empty-mode "push out" refusal included, since an Add is local).
- The refusals, the disabled-row reasons and their order are unchanged. Contrast pairs are unchanged: `--wl-ink` on `plan.bg` 8.6:1, `--wl-ink-muted` on `plan.bg` 5.9:1, `--wl-ink` on `--wl-raise` 6.2:1.
