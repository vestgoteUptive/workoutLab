# Prototype source

Exported from the design canvas: https://claude.ai/artifact/VRmZLyeChxb6WR4zLbkz8w

One `.dc.html` file per screen, named by ID (`UF09-5-Rest.dc.html` = UF-09.5). `canvas.json` holds the layout and flow notes.

These files need the canvas runtime and won't open standalone in a browser. Use them as a reference for layout, copy, states and timer logic (see each file's `class Component`). The canvas stays the place to view and iterate; re-export here when screens change.
