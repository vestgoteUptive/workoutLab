Body figure · round 1
Three redrawn body figures for the Cobalt + state colour system
Same 9 areas and the same BodyFigure API (fill: none, primary, secondary or a coverage step; attention; highlighted; sizes compact, detail, full). Front and back side by side. Secondary muscles use a diagonal hatch. Coverage uses two colours: white = on target, salmon = needs attention; everything else stays the base tint. The figure is drawn in translucent white, so the same art works on blue, red and teal.
1aGeometric blocks
Every area is a flat rounded block with a visible gap between blocks, like a diagram. Easiest to read at thumbnail size and to tap. Least anatomical.
